# 微信小游戏开发规范与框架体系文档总览

本项目基于 **Unity 2022.3 LTS** 针对 **微信小游戏平台 (WebGL / WASM)** 进行定制化开发。  
为了保证游戏在微端环境下的秒开率、高帧率、低内存占用以及团队协作的高效性，特制定本套开发规范与技术规划方案。

## 核心设计准则

1. **首包极简，秒开优先**  
   微信小游戏用户流失率与启动耗时高度相关。初始包体仅保留启动必需资源（微信Logo、启动Loading条），其余业务与美术资源全走 CDN 远程分包下载。
2. **内存严苛，防闪退**  
   微信 iOS 环境对 JavaScript/WASM 堆内存及整体物理内存有极高敏感度（通常建议常驻物理内存控制在 **500MB~800MB** 以内，严格防止突破 1GB 闪退阈值）。
3. **动静分离，合批优先**  
   UI 避免大范围 Mesh Rebuild，严控 DrawCall（2D 游戏控制在 **50~80** 以内），关闭不必要的 `Raycast Target`。
4. **低 GC，避免卡顿**  
   每帧 Update 逻辑严禁 `new` 对象、字符串拼接与闭包分配，高频元素（特效、弹幕、飘字、怪物）全面接入对象池。
5. **平台兼容与优雅降级**  
   低端安卓机与高端机采取分级画质策略（分辨率缩放、粒子数量限制、阴影开关）。
